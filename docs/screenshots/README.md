# Screenshots

Drop README screenshots here. The root `README.md` expects these names:

- `home.png`
- `transactions.png`
- `wallets.png`
- `budgets.png`
- `analytics.png`
- `settings.png`

Rules:

- Keep each file reasonably small (PNG under about 300 KB, or JPG/WebP). They live in git history forever.
- Never import or `require` anything from this folder in app code.
- This folder is excluded in `.easignore`, so it does not end up in the APK/AAB or the EAS upload.
